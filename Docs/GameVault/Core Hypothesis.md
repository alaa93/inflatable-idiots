# Core Hypothesis

**If** two players must share a single, zero-sum pool of air through a permanent hose, **then** the constant mid-action renegotiation ("GIVE ME 40% NOW!") creates a uniquely engaging, funny co-op feeling — strong enough to build a game on.

This is the one thing the whole project exists to test. Everything else (levels, content, meta) is downstream of it.

## How it manifests in systems
- The pool itself: [[Air-Share Mechanic]]
- What the pool changes about each body: [[Inflation State]]
- The visible link that makes the shared resource tangible: [[Air Hose]]
- The level designed to force the renegotiation: [[Fan Trap]]

## Status
**Validated** in a real playtest — see [[MVP Scope and Validation]]. Friends understood it fast, the co-op feeling read as clear and engaging. This unlocked the next phase: [[Networking Architecture]] for an online [[Decision - Steam-first behind wrapper|Steam launch]].
